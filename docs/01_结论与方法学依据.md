## 二、主线口径为何如此设置

流水线为三步：对比预训练 → 提特征（归一化 + 平滑）→ 训分类头。
「主线正确版」指下列四项**同时开启**：

| 设置 | 作用 |
|---|---|
| 逐被试稳健归一化 | 消除被试间幅值差（原始标准差跨被试相差约 1400 倍） |
| `normTrain`（逐通道，统计量只来自训练折） | 消除通道间幅值差 |
| **播放序重排 + 排回** | 使 `running_norm` 沿**各人真实播放顺序**累积 |
| 双向 LDS（按视频分段） | 视频内时序平滑 |

其中**播放序重排是关键**，理由如下。

### `running_norm` 的机制

`running_norm` 是顺序归一化：归一化第 n 个窗口时，在「训练折算出的整体均值方差」与
「该被试自己到目前为止的累计均值方差」之间做加权平均，权重为 `0.99^n`
（n 为窗口在序列中的位置）。它以被试-session 为单位，本数据 `n_session=1`，
即每被试 28 试次 × 30 秒 = **840 个窗口连成一段，跨试次不重置**。

代入实际位置（`data/data_process.py: running_norm_onesubsession`）：

| 位置 | 窗口序号 | 训练集统计量权重 |
|---|---|---|
| 第 1–3 号素材 | 0–89 | 100% → 40% |
| 第 13–16 号素材 | ~360 | 2.7% |
| 第 26–28 号素材 | 750+ | < 0.05% |

**一个窗口被归一化成什么样，取决于它排在第几个。**

### 为何必须重排

数据存盘按**素材编号**排列，而素材编号与情绪严格分块
（1–3 愤怒、4–6 厌恶、…、13–16 中性四个、…、26–28 温柔）。
若不重排，`running_norm` 即沿素材编号累积，**位置与标签必然共变**。

该混杂在所有被试身上方向一致，因此**跨被试交叉验证无法察觉**——
训练集被试有它，测试集的新被试也有它。这不是被试泄露，是任务设计层面的混杂。

重排后，累积顺序变为各人各自的随机播放序，位置与标签的对应即断开。

### 三项检验

| 检验 | 结果 |
|---|---|
| **位置混杂检验**（九类召回 vs 素材编号位置的 Spearman） | 主线 11 项**全部不显著**（\|ρ\|≤0.57, p≥0.112） |
| **`running_norm` 范围消融**（仅改累积范围为每试次重置） | 主线设置下无变化；未重排设置下虚高完全消失 |
| **跨库迁移**（三档库内分数 → TY 零样本） | 库内分数越高，跨库迁移越差 |

对应图见 [`../results/figures/methodology/`](../results/figures/methodology/)。
