# 图

- **根目录**：主线正确版各实验的结果图（逐被试准确率、混淆矩阵、迁移、逐秒动态）。
- **`methodology/`**：**唯一涉及早期错误口径的图**。它们的作用是说明「为什么主线采用
  逐被试归一化 + 播放序重排」这套设置，而不是展示早期结果本身。四张：
  - `05_runningnorm范围消融` —— 只改 running_norm 的累积范围，虚高即消失
  - `03_位置混杂检验_森林图` —— 九类召回 vs 素材编号位置的 Spearman 相关，主线 11 项全不显著
  - `02_库内高分不迁移` —— 库内分数越高，跨库迁移越差
  - `对比_交流素材_runningnorm2x2` —— 关闭 running_norm 后分类器塌陷（见 docs/03 第 6 条）

- **`per_experiment/`**：每个实验一张双联图（左：逐被试准确率条形图；右：行归一化混淆矩阵），
  由 `scripts/build_figures.py` 从 `results/metrics.csv` 统一生成。
  **分类器塌陷的实验会在标题红字标注**（判据：某类召回 >80% 且过 20% 的类不足 1/4）。
